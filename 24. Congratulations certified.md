### Lecture: AWS Certification Paths

**The four AWS certification levels**
- **Foundational**
- **Associate**
- **Professional**
- **Specialty**

AWS recommends **different paths depending on the role** you want. (All paths are published in an AWS document.) If you **already know the cloud and IT**, Cloud Practitioner is **not required** — but it is still considered a good one to have.

**Architecture roles**

| Role | Role description | Recommended path | Deep dive |
|---|---|---|---|
| **Solutions Architect** | Design, develop and manage cloud infrastructure and assets | Cloud Practitioner → **AI Practitioner (Foundational)** if leveraging AI → **Solutions Architect Associate** → **Solutions Architect Professional** | **Security Specialty** |
| **Application Architect** | User interface, middleware, infrastructure | Same as above, **plus Developer Associate** → **DevOps Engineer Professional** | **Solutions Architect Professional** |

**Operations roles**

| Role | Role description | Recommended path | Deep dive |
|---|---|---|---|
| **Systems Administrator** | Install, upgrade and maintain computer components and software; integrate automation processes | Cloud Practitioner → **SysOps Administrator Associate** | **DevOps Engineer Professional** |
| **Cloud Engineer** | Implement and operate an organization's network computing infrastructure; implement security systems to maintain data safety | Cloud Practitioner (Foundational) → **SysOps Administrator Associate** → **Security Specialty** | **DevOps Engineer Professional** + **Advanced Networking Specialty** |

**DevOps roles**

| Role | Role description | Recommended path | Deep dive |
|---|---|---|---|
| **Test Engineer** | Embed testing and quality best practices for software development from design to release throughout the product lifecycle | Cloud Practitioner → **Developer Associate** → **DevOps Engineer** | — |
| **Cloud DevOps Engineer** | Design, deploy and operate large-scale global hybrid cloud computing environments; advocate for end-to-end automated CI/CD pipelines | Cloud Practitioner (Foundational) → **Developer Associate** → optionally **SysOps Administrator** → **Machine Learning Engineer Associate** if working with ML | **DevOps Engineer Professional** |
| **DevSecOps Engineer** | Accelerate enterprise cloud adoption while enabling rapid and stable delivery using CI/CD principles, methodology and technology | Cloud Practitioner → **SysOps Administrator Associate** → **Machine Learning Associate** (if AI/ML projects) → **DevOps Engineer** → **Security Specialty** | — |

**Security roles**

| Role | Role description | Recommended path | Deep dive |
|---|---|---|---|
| **Cloud Security Engineer** | Design computer security architecture and develop detailed cybersecurity designs; develop, execute and track the performance of security systems to protect information | Cloud Practitioner (Foundational) → **AI Practitioner (Foundational)** if working with AI/ML → **SysOps Administrator** → **Security Specialty** | **DevOps Engineer Professional** + **Advanced Networking Specialty** |
| **Cloud Security Architect** | Design and implement enterprise cloud solutions, applying governance to identify, communicate and minimize business and technical risks | Cloud Practitioner → **AI Practitioner (Foundational)** → **Solutions Architect Associate** → **Security Specialty** | **Solutions Architect Professional** |

**Development and networking roles**

| Role | Role description | Recommended path | Deep dive |
|---|---|---|---|
| **Software Development Engineer** | Develop and maintain software across platforms and devices | Cloud Practitioner → **AI Practitioner (Foundational)** → **Developer Associate** → **DevOps Engineer** | — |
| **Network Engineer** | Design LANs and WANs | Cloud Practitioner (Foundational) → **Solutions Architect Associate** → **Advanced Networking Specialty** | **Security Specialty** |

**Data and AI/ML roles**

| Role | Role description | Recommended path | Deep dive |
|---|---|---|---|
| **Cloud Data Engineer** | Automate collection and processing of structured or semi-structured data; monitor data pipeline performance | Cloud Practitioner → **Solutions Architect Associate** → **Data Engineer** (+ **Machine Learning Engineer Associate** if on AI/ML projects) | **Security Specialty** |
| **Machine Learning Engineer** | Research, build and design AI systems that automate predictive models; design ML systems, models and schemes | Cloud Practitioner → **AI Practitioner (Foundational)** → **Solutions Architect Associate** → **Machine Learning Engineer Associate** | **Data Engineer Associate** + **Machine Learning Specialty** |
| **Prompt Engineer** | Design, test and refine text prompts to optimize the performance of an AI language model | Cloud Practitioner → **AI Practitioner (Foundational)** — *very important for this role* → **Machine Learning Engineer Associate** | **Machine Learning Specialty** |
| **Machine Learning Ops Engineer** | Operations side — maintain the platform and infrastructure | Cloud Practitioner → **AI Practitioner** → **Solutions Architect Associate** → **Machine Learning Associate** | **Data Engineer** + **DevOps Engineer** |
| **Data Scientist** | Develop and maintain AI/ML models to solve business problems; train and fine-tune models and evaluate their performance | Cloud Practitioner (Foundational) → **AI Practitioner (Foundational)** → **Solutions Architect Associate** → **Machine Learning Engineer Associate** → **Machine Learning Specialty** | — |

## Section: Congratulations - AWS Certified Cloud Practitioner — Key Takeaways

**Most important concepts**
- AWS certifications come in **four levels**: **Foundational**, **Associate**, **Professional**, **Specialty**.
- **Cloud Practitioner is the Foundational entry point** for almost every recommended path, but it is **optional for people who already know the cloud and IT** (still recommended).
- **AI Practitioner (Foundational)** is the second foundational certification, recommended whenever the role touches **AI/ML** — and it is called out as **especially important for a Prompt Engineer**.
- The **Associate tier splits by discipline**: **Solutions Architect Associate**, **Developer Associate**, **SysOps Administrator Associate**, **Data Engineer Associate**, **Machine Learning Engineer Associate**.
- The **Professional tier has two certifications**: **Solutions Architect Professional** and **DevOps Engineer Professional** — they appear as the natural next step or as the "deep dive" for most paths.
- The **Specialty tier** referenced here: **Security Specialty**, **Advanced Networking Specialty**, **Machine Learning Specialty**.
- **Paths are role-driven, not linear**: the recommended sequence depends on whether you sit in architecture, operations, DevOps, security, development/networking, or data/AI-ML.

**How the concepts relate**
- Nearly every path is **Foundational → Associate → Professional**, with a **Specialty certification as the "deep dive"** — so the tiers map onto career progression rather than being independent tracks.
- **Security Specialty and DevOps Engineer Professional recur across many paths** as the deep-dive options, reflecting how security and automation cut across all roles — the same cross-cutting theme as the Well-Architected pillars.
- **AI/ML has been layered onto the traditional paths** rather than replacing them: architecture, DevOps, security, data and ML roles all now include **AI Practitioner** and/or **Machine Learning Engineer Associate** as optional or required steps.
- The **role descriptions themselves explain the ordering**: operations-focused roles route through **SysOps Administrator**, build-focused roles through **Developer Associate**, and design-focused roles through **Solutions Architect Associate**.

**Key terminology to remember**
- Foundational, Associate, Professional, Specialty certification levels
- Cloud Practitioner (Foundational), AI Practitioner (Foundational)
- Solutions Architect Associate, Developer Associate, SysOps Administrator Associate, Data Engineer Associate, Machine Learning Engineer Associate
- Solutions Architect Professional, DevOps Engineer Professional
- Security Specialty, Advanced Networking Specialty, Machine Learning Specialty
- Role names: Solutions Architect, Application Architect, Systems Administrator, Cloud Engineer, Test Engineer, Cloud DevOps Engineer, DevSecOps Engineer, Cloud Security Engineer, Cloud Security Architect, Software Development Engineer, Network Engineer, Cloud Data Engineer, Machine Learning Engineer, Prompt Engineer, Machine Learning Ops Engineer, Data Scientist

**Key distinctions/comparisons**
- **Foundational vs. Associate vs. Professional vs. Specialty**: entry-level breadth vs. role-specific competence vs. advanced role mastery vs. narrow deep expertise (security, networking, ML).
- **Solutions Architect Associate vs. Developer Associate vs. SysOps Administrator Associate**: designing systems vs. building applications vs. operating and maintaining them.
- **Solutions Architect Professional vs. DevOps Engineer Professional**: the deep dive for architecture/security-architecture paths vs. the deep dive for operations, DevOps and engineering paths.
- **Cloud Security Engineer vs. Cloud Security Architect**: routes through **SysOps Administrator** (operational security) vs. through **Solutions Architect Associate** (designing secure enterprise solutions with governance).
- **Machine Learning Engineer vs. Machine Learning Ops Engineer vs. Data Scientist vs. Prompt Engineer**: build/design AI systems vs. maintain the ML platform and infrastructure vs. develop, train and fine-tune models for business problems vs. design and refine prompts for language models.
- **Cloud Data Engineer vs. Machine Learning Engineer**: data pipelines and structured/semi-structured data processing (**Data Engineer Associate**) vs. predictive models and ML system design (**Machine Learning Engineer Associate**).

**You should be able to explain:**
- The four AWS certification levels and which certifications sit in each.
- Why Cloud Practitioner is the usual starting point and when it can be skipped.
- Which Associate certification follows for an architecture, development, operations, data, or ML career.
- Which two Professional certifications exist and which paths lead to each.
- When the Security Specialty, Advanced Networking Specialty and Machine Learning Specialty are recommended as deep dives.
- Where AI Practitioner and Machine Learning Engineer Associate fit into otherwise non-ML paths.
